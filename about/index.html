About

Hi there! I’m Adam, and I’m a software engineer. On this blog I write about cool stuff I stumble upon while writing software.

I’ve worked in various roles throughout my career, starting off in desktop application development, then full-stack, then back-end, then data engineering, then on to my current role, in which i’m working on Semantic Search engines and Agents.

I have a wide-variety of interests, mostly fueled by curiosity; the latest things i’m working on are a Rust implementation of HNSW, in order to get a better understanding of the language, and a nutrition app to help with meal planning.

Feel free to check out my projects on GitHub, including the source code of this blog.
